---
title: Guide Admin
description: Un guide admin pour le control plane d'OKDP.
---

Le guide d'administration explique à l'administrateur comment gérer un cluster OKDP. Il décrit la gestion du cycle de vie de tous les services, la manière de les connecter à un stockage externe ou à un serveur de base de données, ainsi que leur surveillance.

1. [Administration des projets](/fr/admin-guide/project-administration) : explique comment gérer et surveiller les projets.
2. [Connexions et gestion des secrets externes](/fr/admin-guide/connections-and-external-secrets-management) : explique comment créer, supprimer et modifier des connexions, des secrets externes et des référentiels de secrets externes.
3. [Déploiement des services](/fr/admin-guide/service-deployment) : instructions pour le déploiement des services OKDP, depuis la console ou sous forme de fichiers dans le dépôt Git de déploiement.
4. [Mise à niveau depuis KuboCD](/fr/admin-guide/upgrade-from-kubocd) : ce qui change pour une plateforme déployée avec KuboCD, et l'ordre des opérations.
